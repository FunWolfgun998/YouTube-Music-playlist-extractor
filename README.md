# YouTube Music playlist extractor (v3.0)
This script returns a TXT, CSV, or JSON file containing detailed song information from any YouTube Music playlist.<br>
It can extract: **Title, Artist, Album, Link, and Video ID**.

## 🚀 How to use
- Visit a Playlist's page on YouTube Music (URL looks like: `https://music.youtube.com/playlist?list=...`).
- Scroll down to the bottom manually to load all songs of the playlist.
- Press `Ctrl` + `Shift` + `J` or `F12` to open the Developer Console.
- Copy the script from this repo (found in `YouTube-Music-playlist-extractor.js`).
- Paste the code into the Developer Console on the YTM Tab, and hit `Enter`.
- Answer the brief setup questions in the pop-up windows.
- Great, you're done! Your file will download automatically.
